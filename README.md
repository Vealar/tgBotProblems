### Telegram-бот для работы с базой математических задач

Telegram-бот для доступа к базе данных математических задач, позволяющий пользователям просматривать задачи и решения, выполнять фильтрацию и использовать расширенный поиск. Проект реализован на Python с использованием фреймворка aiogram, SQLAlchemy для взаимодействия с базой данных и PostgreSQL в качестве СУБД.
